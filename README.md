# 9-Maktab — School Website

A modern responsive website for **School No. 9 of Yunusabad District, Tashkent, Uzbekistan**.

The project was created as a practical web development project using pure **HTML, CSS, and JavaScript**, without frontend frameworks.

## 🌐 Live Demo

**Website:** https://9-maktab-uz.netlify.app

## 📖 About the Project

This website provides students, parents, teachers, and visitors with a convenient way to access important school information and services.

The website includes:

* School information
* Announcements and news
* Photo gallery
* Information for students, parents, and teachers
* Electronic contact form
* Government and education portal links
* Responsive navigation
* Language switching
* Accessibility and display options

## 🛠️ Technologies

* **HTML5** — page structure and semantic markup
* **CSS3** — styling, responsive design, animations, and layout
* **JavaScript** — interactive elements and dynamic functionality

No frontend framework is required to run this project.

## 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/Abdulloh-01/9-maktab.git
```

Open the project directory:

```bash
cd 9-maktab/9-maktab-static
```

Then open `index.html` in your browser.

Alternatively, you can use a local development server such as VS Code Live Server.

# 9-Maktab — Сайт школы

Современный адаптивный веб-сайт для **9-й общеобразовательной школы Юнусабадского района, города Ташкента, Узбекистан**.

Проект создан как практическая работа по веб-разработке с использованием чистых **HTML, CSS и JavaScript**, без frontend-фреймворков.

## 🌐 Демо

**Сайт:** https://9-maktab-uz.netlify.app

## 📖 О проекте

Сайт предоставляет ученикам, родителям, учителям и посетителям удобный доступ к информации и основным сервисам школы.

На сайте представлены:

* Информация о школе
* Новости и объявления
* Фотогалерея
* Разделы для учеников, родителей и учителей
* Электронное обращение
* Ссылки на государственные и образовательные порталы
* Адаптивная навигация
* Переключение языка
* Настройки отображения и доступности

## 🛠️ Используемые технологии

* **HTML5** — структура страниц и семантическая разметка
* **CSS3** — стилизация, адаптивная верстка, анимации и расположение элементов
* **JavaScript** — интерактивные элементы и динамическая функциональность

Для работы проекта frontend-фреймворки не требуются.
